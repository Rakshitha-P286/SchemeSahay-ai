# SIH Demo Flow

1. Register
2. Complete profile
3. Upload an income/caste/identity/project document
4. Describe a business need in natural language
5. Show AI scheme matches
6. Open a scheme
7. Show evidence-based eligibility
8. Run Application Readiness
9. Show missing documents and financial mismatch
10. Fix profile/document inputs
11. Re-run readiness
12. Run financial what-if
13. View channel partners
14. Create application
15. Submit demo application
16. Show tracking timeline
